プライバシーポリシー / Privacy Policy

最終更新 / Last updated: 2026-10-31

このページは、lost tape. のウェブサイトと、動画投稿用の道具「lost tape uploader」（以下「本ツール」）が、情報をどう扱うかを説明します。

This page explains how the lost tape. website and our video upload tool "lost tape uploader" (the "Tool") handle information.

1. 本ツールについて / About the Tool

本ツールは YouTube API Services を使用しています。本ツールを使うことで、YouTube利用規約に同意したことになります。Googleによる情報の扱いはGoogleプライバシーポリシーをご覧ください。

The Tool uses YouTube API Services. By using the Tool, you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles information.

本ツールは、lost tape. の運営者が、自分の作った動画を自分のYouTubeチャンネルに投稿するためだけに使います。一般の人に提供はしていません。

The Tool is used only by the operator of lost tape. to upload our own videos to our own YouTube channel. It is not offered to the public.

2. 使う情報 / Information we access

  • 運営者のYouTubeチャンネルの名前（正しいチャンネルに投稿するかの確認のため）
    The name of our own YouTube channel, to confirm we upload to the right channel.
  • 投稿する動画のファイル、タイトル、説明文、タグ、公開範囲
    The video file, title, description, tags and privacy setting of the videos we upload.
  • Googleから発行される認証用の情報（トークン）
    Authorization tokens issued by Google.

他のユーザーや視聴者の個人情報は、取得・保存・利用しません。

We do not access, collect, store or use personal information of any other users or viewers.

3. 保存と共有 / Storage and sharing

認証用の情報は、運営者のパソコンの中にだけ保存し、外部のサーバーには送りません。投稿の記録（どの動画をいつ投稿したか）も同じパソコンにだけ保存します。これらの情報を第三者に売ったり、渡したりすることはありません。

Authorization tokens are stored only on the operator's own computer and are never sent to any other server. A log of which videos were uploaded and when is stored on the same computer. We never sell or share this information with third parties.

4. 許可の取り消しとデータの削除 / Revoking access and deleting data

本ツールへの許可は、いつでもGoogleアカウントのセキュリティ設定から取り消せます。取り消すと、保存されている認証用の情報は使えなくなり、運営者はそれを削除します。

You can revoke the Tool's access at any time from the Google security settings page. Once revoked, the stored tokens no longer work and we delete them.

保存している情報（認証用の情報と投稿の記録）は、YouTube API Services から得た情報を含め、30日を超えて古いまま使い続けることはありません。削除を希望する場合は、下の連絡先にメールをいただければ7日以内に削除します。

We do not keep information obtained from YouTube API Services (tokens and the upload log) for more than 30 days without refreshing it. To request deletion, email the contact address below and we will delete it within 7 days.

利用規約 / Terms of Service

5. ウェブサイト / This website

このウェブサイトは GitHub Pages で公開しています。Cookieやアクセス解析は使っていません。GitHubによる情報の扱いはGitHubのプライバシーステートメントをご覧ください。

This website is hosted on GitHub Pages. We do not use cookies or analytics. See the GitHub Privacy Statement for how GitHub handles information.

6. 変更 / Changes

このポリシーを変えるときは、このページを更新し、上の日付を書き換えます。

If we change this policy, we will update this page and the date above.
